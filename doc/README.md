# AppsFlyer Flutter plugin — documentation

Welcome. These guides follow the integration journey, from adding the plugin to going
live and troubleshooting. Follow them in order for a first integration, or jump to the
topic you need.

## Integration journey

1. **[Installation](installation-guide.md)** — add the package and configure native (iOS/Android) dependencies.
2. **[Getting started](getting-started.md)** — create the SDK instance, `initSdk`, the SDK 7 session-ready start model, and iOS 14 / ATT setup.
3. **[Deep linking](deep-linking.md)** — OneLink / Unified Deep Linking, deferred & direct links, and Android/iOS link setup.
4. **[In-app events & ad revenue](in-app-events.md)** — log custom events and ad-revenue events.
